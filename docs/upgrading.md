# Upgrading

This page says what to do when you move to a new release. It covers each
change to the beta part of the tool that you may have to act on:

- the config format;
- where and how the tool stores records in the vault, which
  [UC-1 §3](use-cases/uc-01-app-credential-sync.md#records-in-the-store)
  lists;
- exit codes;
- the JSON output's schemas.

The README's *Status* says which part of the tool is beta. [The
changelog](../CHANGELOG.md) lists every change, and this page adds what to do
about the ones above. A release with nothing here needs nothing from you.

Read every section between the release you have and the one you are moving to,
oldest first.
